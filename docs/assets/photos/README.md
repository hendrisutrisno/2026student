# Public website photos

Upload approved public images for your profile, semester cards, and research showcases here.

- Use a square profile photo, about 400 to 800 pixels wide.
- Use a landscape image for semester and showcase cards.
- Keep each image below 2 MB when possible. Use `.jpg`, `.png`, or `.webp`.
- Use short filenames with lowercase letters and hyphens, such as `robot-test.png`.
- Remove private information and location metadata before uploading a photo.

Set `student.photo` in `docs/_config.yml` to `/assets/photos/profile.jpg`.
Set `image` in a semester or showcase file to `/assets/photos/robot-test.png`.
Do not include the repository name in these image paths. The site adds it.
Remove the `photo` or `image` field when you do not need an image.

These files are public on the website. Put private meeting figures in
`meetings/assets/` outside `docs/`, and keep the source repository private.
